# Trabajo en este proyecto

Leer README.md y PRODUCT.md antes de implementar. No confundir propuestas con funcionalidades existentes.

- Mantener el proyecto local y mínimo; validar Codex antes de construir infraestructura.
- No modificar ni reorganizar repositorios de libros vecinos. Trabajar con material ficticio o copias privadas autorizadas.
- No incluir manuscritos, conversaciones, imágenes privadas ni credenciales en commits.
- Conservar control editorial: diagnóstico no autoriza reescritura; una propuesta no es canon.
- Reutilizar build-novel como flujo editorial, verificando su instalación y licencia antes de distribuirla; no copiar automáticamente habilidades globales.
- Toda lógica no trivial debe tener una comprobación ejecutable. No declarar pruebas pendientes como exitosas.
- Sin remoto, publicación, licencia definitiva ni servicios de pago hasta una decisión explícita del usuario.
