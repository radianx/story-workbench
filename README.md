Nombre de trabajo, no marca confirmada. Un espacio local para escribir y revisar historias con IA, conservando el control del autor y la continuidad entre sesiones.

Estado: prueba mínima de Codex App Server completada, 2026-09-08. Hay un script ejecutable; todavía no hay editor.
