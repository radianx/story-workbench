Linux text-to-speech uses the separately installed espeak-ng system package through its command line.
It is a .deb dependency; this runtime does not bundle or modify eSpeak NG binaries/data.
Windows text-to-speech uses System.Speech installed with Windows.
No voices or recordings belonging to users are included.
